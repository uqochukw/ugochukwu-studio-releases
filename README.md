# Ugochukwu Studio — releases

Windows installers and the update feed for **Ugochukwu Studio**, the desktop editor for
[ugochukwu.ng](https://ugochukwu.ng). This repository holds no source code.

**Install:** open [the latest release](https://github.com/uqochukw/ugochukwu-studio-releases/releases/latest)
and download the file ending in `_x64-setup.exe`. Installed copies update themselves.

Releases are published automatically by the build pipeline; please do not edit them by hand.
